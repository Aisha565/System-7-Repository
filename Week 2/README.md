## Setup (Windows PowerShell)
Run from the repository root:
```powershell
python -m pip install -r requirements.txt
python "Week 2\day-08\dataset_exploration.py"
python "Week 2\day-09\train_test_split.py"
python "Week 2\day-10\linear_regression.py"
python "Week 2\day-11\multiple_regression.py"
python "Week 2\day-12\regression_comparison.py"
python "Week 2\day-13\classification_model.py"
python "Week 2\day-14\summary.py"
```

The included house-price and student-performance CSV files are small learning datasets created for this beginner assignment. House-price values are illustrative, not real market estimates. The Iris dataset is loaded from scikit-learn.
