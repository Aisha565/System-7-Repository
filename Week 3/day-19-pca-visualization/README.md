# Day 19 - Principal Component Analysis (PCA)

## Q12: PCA Visualization

- Loaded the Iris dataset.
- Standardized features using StandardScaler.
- Reduced four features into two principal components.
- Applied K-Means clustering with three clusters.
- Calculated explained variance ratio.
- Visualized clusters using a 2D scatter plot.

## Results

- Original Dataset Shape: (150, 4)
- Reduced Dataset Shape: (150, 2)
- PC1 Explained Variance: 72.96%
- PC2 Explained Variance: 22.85%
- Total Explained Variance: 95.81%
