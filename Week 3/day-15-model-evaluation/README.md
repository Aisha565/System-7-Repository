# Day 15: Model Evaluation

## Topics Covered
- Train-test split and stratification
- Classification metrics
- Regression metrics
- 5-fold cross-validation
- ROC curves and AUC

## Practice Questions

1. Split the Iris dataset into 80% training and 20% testing data using stratification.
2. Train a Random Forest classifier and calculate accuracy, precision, recall, F1-score and confusion matrix.
3. Calculate MAE, MSE, RMSE and R2 using NumPy and verify with Scikit-learn.
4. Perform 5-fold cross-validation on Logistic Regression, Decision Tree and Random Forest.
5. Compare ROC curves and AUC scores of Logistic Regression and Random Forest.

## Learning Notes

- Train-test split evaluates a model on unseen data.
- Cross-validation checks model performance across multiple data splits.
- Precision measures correct positive predictions.
- Recall measures how many actual positives are identified.
- F1-score balances precision and recall.
- ROC curve compares true positive rate with false positive rate.
- AUC measures the model's ability to distinguish classes.
- MAE, MSE and RMSE measure regression prediction errors.
- R2 measures how much variation the model explains.

## Tools
Python, NumPy, Matplotlib and Scikit-learn.
