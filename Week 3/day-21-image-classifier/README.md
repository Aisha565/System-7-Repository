# Day 21 - Image Classification and Transfer Learning

## Objective
Build and compare a CNN model from scratch and a pretrained MobileNetV2 model.

## Dataset
CIFAR-10 Dataset

- Training Images: 5,000
- Testing Images: 1,000
- Image Classes: 10
- Original Image Size: 32x32

## Tasks Completed
1. Built a CNN model from scratch.
2. Trained the CNN model for 5 epochs.
3. Implemented MobileNetV2 Transfer Learning.
4. Froze pretrained base model layers.
5. Trained MobileNetV2 for 3 epochs.
6. Compared model accuracy.
7. Visualized model accuracy and image predictions.

## Results

| Model | Test Accuracy |
|---|---:|
| CNN from Scratch | 44.80% |
| MobileNetV2 | 83.10% |

Improvement: 38.30 percentage points.

## Key Learnings
- CNN architecture and image classification.
- Transfer Learning using MobileNetV2.
- Freezing pretrained layers.
- Model evaluation and accuracy comparison.
- Image prediction visualization.

## Tools
Python, TensorFlow, Keras, NumPy, Matplotlib, Google Colab.
